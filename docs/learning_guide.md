# 英単語学習支援システム 学習ガイド

## 1. 学習目的

本システムでは、参考書をもとに英単語の意味や語源、派生語などを自分で入力し、教材を構築しながら学習します。

単語の意味を覚えるだけでなく、語源や単語同士の関係を理解することを目的としています。

## 2. 基本的な学習の流れ

1. 参考書を読む。
2. 教材を登録する。
3. 登録内容を確認する。
4. 今日のテストを受ける。
5. 間違えた単語を復習する。
6. 必要に応じて自由テストや語源ネットワークを利用する。
7. 学習記録を確認する。

## 3. 教材登録

参考書のChapter・Sectionに沿って教材を登録してください。

参考書の1つのSectionを、システムでは1つのStackとして扱います。

### Chapter情報

- Chapter番号
- 接頭辞
- 接頭辞の意味

### Stack情報

- Stack番号
- メイン単語
- 共通する語根
- 語根の意味

### 単語情報

- 英単語
- 品詞
- 日本語の意味
- 語の構成
- 構成要素の意味
- 派生語とその意味

参考書を読みながら、掲載されている単語を登録してください。

## 4. 教材の確認

教材登録後、参考書と登録内容を照らし合わせてください。

- 英単語の綴り
- 品詞と意味
- 接頭辞・語根
- 語の構成
- 派生語

誤りがあれば編集してください。

確認が完了したら、Stackの確認操作を行ってください。

確認済みの単語がテストの出題対象となります。

## 5. 今日のテスト

教材の登録・確認後に実施してください。

確認済みの単語のうち、まだ今日のテストで回答していない単語が出題されます。

以前に登録した単語でも、今日のテストで未回答の場合は出題されます。

### テスト形式

- 英単語から日本語の意味を選択する。
- 4つの選択肢から回答する。
- 回答後に正誤と正解を確認する。
- 必要に応じて語源ネットワークを確認する。

## 6. 自由テスト

登録済みの教材を自由に復習するための機能です。

出題範囲を選択できます。

- 全単語
- Chapter指定
- Stack指定
- 誤答集

また、過去の回答結果に応じた推奨出題を利用できます。

苦手な単語や、まだ十分に学習できていない単語の復習に活用してください。

## 7. 誤答集

テストで間違えた単語を確認できます。

以下の情報を確認し、復習に活用してください。

- 英単語
- 日本語の意味
- 語の構成
- 派生語
- 語源ネットワーク

間違えた単語は、その後のテストで2回連続して正解すると誤答集から除外されます。

## 8. 語源ネットワーク

登録した教材をもとに、接頭辞・語根・英単語の関係が自動的に表示されます。

### 主な操作

- クリック：詳細情報の表示
- ダブルクリック：表示の中心を変更
- ドラッグ：表示位置の調整
- ズーム：拡大・縮小
- 検索：単語や語源の検索
- Chapter・Stackの指定：表示範囲の変更

単語の意味だけでなく、共通する語根や関連する単語にも注目してください。

## 9. 学習記録

自分の学習状況を確認できます。

### 教材登録状況

- 登録したChapter数
- 登録したStack数
- 登録単語数
- 確認済み単語数
- 教材の確認率

### 登録履歴

- 日別の登録数
- 確認数
- 編集数
- 削除数

### 学習時間

- 教材登録・編集画面の表示時間
- 教材登録・編集画面の推定操作時間

### テスト履歴

- 正答率
- 回答数
- 回答時間
- Chapter別の正答率

### 語源ネットワーク

- 日別の利用回数
- 表示時間
- 推定操作時間

テスト内での語源ネットワーク利用は、ネットワーク利用状況の集計対象外です。

## 10. 学習時の注意事項

- 指定された参考書を使用してください。
- 教材は自分自身で登録してください。
- 他の学習者の教材データをコピーしないでください。
- テスト中は参考書や辞書を見ずに回答してください。
- 教材データや学習ログを直接編集・削除しないでください。
- システムに不具合が発生した場合は報告してください。

## 11. 学習データの保存・提出

教材データと学習ログは、使用しているPC内に保存されます。

- vocab_data/：登録した教材データ
- learning_logs/：学習ログ

学習期間中はこれらのデータを削除しないでください。

提出時期と具体的な提出方法については、別途案内します。
